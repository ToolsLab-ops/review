使い方

  1. 調べたいページのURL（例: https://example.com/）を入力します。https:// を省くと、https:// として調べます。
  2. 「リダイレクトをたどって…」にチェックを入れると、転送先の最終的なページのヘッダーを表示します。外すと、入力したURLそのものの応答を表示します。
  3. 「取得」を押すと、ステータスコードとヘッダーの一覧が表示されます。

よく見るヘッダー

ヘッダー内容
content-type返ってきたデータの種類と文字コード（text/html; charset=utf-8 など）
cache-controlブラウザやCDNがどれだけキャッシュしてよいか（max-age は秒数）
locationリダイレクト（3xx）の転送先
serverWebサーバーやサービスの名前（cloudflare・nginx など）
last-modified / etag更新日時と版の目印。変更がなければ再読み込みを省くために使われる
strict-transport-security常にHTTPSで開くようブラウザに指示する設定（HSTS）

こんなときに

  • サイトを更新したのに反映されない：cache-control や age を見て、CDNのキャッシュが残っていないか確認する
  • サイトの引っ越し後：ステータスコードが200になっているか、旧URLが301で転送されているか確認する
  • どのサービスで配信されているか知りたい：server や x-cache などのヘッダーからCDNやホスティングを推測する

ステータスコードの目安

200番台は正常、300番台は転送、400番台は「ページがない・アクセスできない」などの要求側の問題、500番台はサーバー側の問題です。520〜530番台はCloudflare独自のコードで、配信元のサーバーに接続できないことを表します。
