## 1. プログラミング副業で稼げる仕事の種類

### 単価・難易度別まとめ

| 副業の種類 | 単価目安 | 必要スキル | 難易度 |
|-----------|---------|----------|--------|
| HTML/CSSコーディング | ¥3,000〜30,000/件 | HTML, CSS | ★★☆ |
| WordPressサイト制作 | ¥30,000〜200,000/件 | WordPress, PHP | ★★★ |
| LP（ランディングページ）制作 | ¥20,000〜100,000/件 | HTML, CSS, JS | ★★★ |
| Webアプリ開発 | ¥50,000〜/件 | JavaScript / Python等 | ★★★★ |
| プログラミング記事執筆 | ¥3,000〜15,000/件 | 知識 + 文章力 | ★★☆ |
| バグ修正・保守 | ¥1,000〜5,000/時間 | 実装経験 | ★★★ |

**初心者が最初に狙うべき**: HTML/CSSコーディング → WordPressサイト制作の順がロイヤルロードです。

## 2. おすすめの学習方法 — スクールvs独学

### 独学（ChatGPT + 無料リソース）

- **Progate**: 月¥1,078でWeb言語の基礎を習得
- **freeCodeCamp / Udemy**: 体系的なカリキュラム（英語）
- **ChatGPT**: コードのエラー解説・理解補助に最適
- 自由なペースで学べる反面、つまずいたときに挫折しやすい

### プログラミングスクール（最短ルート）

**忍者CODE**は、月額制で通い放題スタイルのプログラミングスクールです。

| 特徴 | 内容 |
|------|------|
| 学習コンテンツ | HTML/CSS/JavaScript/PHP/WordPress対応 |
| 料金 | 月額¥1,078〜（月額プラン・買い切りあり） |
| サポート | チャットサポート + コードレビュー |
| 向いている人 | 副業でWeb制作を始めたい社会人 |

副業レベルのHTML/CSS → WordPress制作スキルを、**3〜4ヶ月**で習得することを目標にするとリアルです。

---

## 3. 案件獲得 — クラウドソーシングの使い方

### クラウドワークスでプログラミング案件を取る手順

1. **プロフィールにスキルを具体的に書く**（例: 「HTML/CSS, WordPress, レスポンシブ対応可」）
2. **ポートフォリオを添付する**（自作サイト1〜2本でOK）
3. **最初は低単価でも積極的に応募**して実績・評価を積む
4. **実績5件以上で単価交渉**しやすくなる

**初心者によくある失敗**: 提案文が「〜できます」という能力アピールだけになる。「御社のLPに〇〇を実装することで〜というメリットがあります」という提案型に変えると通りやすくなります。

### Workshipで高単価案件へ

実績が15〜20件ほど積めたら、[Workship](https://goworkship.com/){:rel="nofollow"}への登録が有効です。IT系フリーランス向けの手数料0%プラットフォームで、月20〜50万円の継続案件が多数掲載されています。

---

## 4. プログラミング副業で月10万円を稼ぐシミュレーション

### パターンA: WordPress制作（月4〜5件）

- 単価: ¥25,000/件 × 4件 = ¥100,000
- 作業時間: 1件20〜30時間 × 4件 = **月80〜120時間**

### パターンB: HTML/CSS + 保守作業（週10時間）

- コーディング: ¥3,000/時間 × 40時間/月 = ¥120,000
- 週10時間稼働で達成可能なライン

**現実的なスケジュール**: スクールで3〜4ヶ月学習 → 低単価案件で5〜10件実績 → 月10万円ラインに到達（始めてから6〜8ヶ月目が目安）

---

## 5. AIを使った開発効率化

プログラミング副業でのAI活用は、もはや必須です。

- **ChatGPT**: バグ原因の特定・コードの解説・リファクタリング提案
- **GitHub Copilot**: コード補完・ボイラープレートの自動生成
- **Cursor**: AIが組み込まれたコードエディタ

AIで作業時間を1/3に短縮し、同じ時間でより多くの案件をこなせます。

---

## まとめ

プログラミング副業で月10万円を達成するには、次の3ステップが現実的です。

1. **スクール or 独学で3〜4ヶ月学習**（HTML/CSS/WordPress）
2. **クラウドワークスで低単価案件5〜10件をこなし実績を作る**
3. **単価を上げ、Workshipなど高単価チャネルに移行する**

AIを活用すれば学習も案件対応も効率化でき、スタートまでの時間を大幅に短縮できます。
