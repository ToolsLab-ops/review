副業で収入を得たら、税金の知識は必須です。「少し稼いだだけだから関係ない」と思っていると、のちのちペナルティを受ける可能性があります。この記事では、**会社員が副業をする際に知っておくべき確定申告のすべて**を解説します。

---

## 1. 副業収入はいくらから確定申告が必要？

### 年間20万円ルール（会社員の原則）

会社員（給与所得者）の場合、**副業収入の合計が年間20万円を超えると確定申告が必要**です。

| 副業収入（年間） | 確定申告 | 住民税申告 |
|--------------|---------|----------|
| 20万円以下 | 原則不要 | 必要な場合あり |
| 20万円超 | **必要** | 確定申告で兼ねる |

> **注意**: 医療費控除・ふるさと納税（確定申告方式）など他の控除で確定申告をする場合は、20万円以下の副業収入も合わせて申告が必要です。

### 「収入」と「所得」の違い

確定申告で申告するのは「所得」（収入 − 経費）です。

- クラウドワークス等の副業: 受取金額 − PC代・通信費等の経費 = **雑所得**
- フリーランス（事業的規模）: 売上 − 経費 = **事業所得**

副業レベルであれば「雑所得」として計算するケースが大半です。経費をきちんと記録しておくと節税になります。

## 2. 会社に副業がバレる仕組みと対策

### バレる最大の原因：住民税の「特別徴収」

会社員の住民税は、通常、会社が給与から天引きして納める「**特別徴収**」です。副業収入があると住民税額が増加し、その増加分が会社に通知されます。

```
【特別徴収の場合】
副業収入あり
 → 確定申告
 → 市区町村が住民税を計算
 → 「この人、住民税が例年より多いな…」と会社が気づく
```

### 対策：住民税を「普通徴収」に切り替える

確定申告書の「住民税に関する事項」欄で、副業分の住民税を「**自分で納付（普通徴収）**」に変更します。

```
確定申告書 第二表
「住民税・事業税に関する事項」
 → 給与以外の所得に係る住民税の徴収方法
 → ☑ 自分で納付（普通徴収）  ← これを選ぶ
```

これにより、副業分の住民税は会社経由ではなく、自分の口座から直接引き落とし or 納付書で払うことになります。

> **注意**: 一部の自治体では「普通徴収が選べないケース」もあります。お住まいの市区町村のルールを事前に確認してください。

## 3. 確定申告が必要な副業の種類

| 副業の種類 | 所得区分 | 備考 |
|-----------|---------|------|
| クラウドワークス・ランサーズ | 雑所得 | 源泉徴収なし |
| ブログ・アフィリエイト | 雑所得 or 事業所得 | 収入継続性による |
| 投資・FX・仮想通貨 | 雑所得 | 別途税制規定あり |
| ハンドメイド販売（minne等） | 雑所得 | 趣味の範囲を超えたら |
| YouTube広告収入 | 雑所得 | 規模次第で事業所得 |
| 不動産収入 | 不動産所得 | 別途申告 |

## 4. 確定申告の手順（会社員の副業版）

### 必要な書類

- **源泉徴収票**（本業の会社から年末にもらう）
- **副業の収入・経費のまとめ**（領収書・振込明細など）
- **マイナンバーカード or 通知カード + 身分証明書**

### ざっくりした手順

1. **収支を集計する**（1月〜12月の副業収入 − 経費）
2. **確定申告書を作成**（e-Tax / 確定申告ソフト）
3. **住民税を「普通徴収」に設定**
4. **2月16日〜3月15日の間に提出**（電子申告 or 郵送 or 窓口）
5. **税金を納付**（4〜5月ごろに納付書が届く）

## 6. 経費で節税できる主な費用

副業に関連する支出は経費として計上でき、課税所得を下げられます。

| 経費の例 | 具体例 |
|---------|-------|
| **通信費** | スマホ代・インターネット代（按分） |
| **PC・周辺機器** | 副業用PCの購入費（10万円以上は減価償却） |
| **書籍・講座代** | スキルアップのための教材費 |
| **ソフトウェア** | 会計ソフト・有料AIツールの利用料 |
| **交通費** | 取引先への移動費 |
| **作業スペース** | 自宅の家賃を按分（事業利用部分のみ） |

> 経費として認められるには「副業のために使った」という記録が必要です。領収書・レシートを日頃から保管しておきましょう。

3. **確定申告ソフトを使えば初心者でも1〜2時間で完了する**
