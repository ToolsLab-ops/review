副業をしている会社員が確定申告を必要とする主なケースは以下の通りです。

- **副業収入（雑所得）が年間20万円を超えた場合**
- 複数の会社から給与を受け取っている場合
- 医療費控除・住宅ローン控除（初年度）などの還付申告をしたい場合
- フリーランス・個人事業主として青色申告を選択している場合

確定申告には**青色申告**（最大65万円控除）と**白色申告**（簡易だが控除が少ない）の2種類があります。副業で収益を上げているなら青色申告の届出を出して節税することをおすすめします。

**ソリマチ**は農業・個人事業主・小規模法人向けの会計ソフトです。「農業簿記」は農家や農業法人の経営管理に特化しており、一般的なITツール利用者よりも**農業を副業・本業にしている方**に向いています。

### ソリマチの強み
- 作物（作目）ごとの収支など、農業特有の会計に対応
- 農業所得用の青色申告決算書を作成できる
- 買い切り型なので月額・年額の利用料がかからない（サポートは別料金。最新版「農業簿記13」は2026年6月発売、販売店価格は6万円台）

### ソリマチの注意点
- 一般の副業者（デジタルコンテンツ・ブログ・せどりなど）には向かない
- スマホアプリが弱く、PC中心の操作
- freeeやマネーフォワードほどの自動連携機能がない

**農業・農家の副業・個人事業の帳簿管理にはソリマチが最適です。一般的な副業者にはfreeeか弥生をおすすめします。**

## 6. アプリに頼らない方法（e-Tax + 手動）

<figure style="text-align:center;margin:2rem auto;max-width:800px;"><svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 800 160" style="max-width:100%;height:auto;border-radius:10px;display:block;"><rect width="800" height="160" fill="#0f172a" rx="10"/><rect x="30" y="30" width="160" height="100" fill="#334155" rx="8"/><text x="110" y="68" text-anchor="middle" font-family="sans-serif" font-size="12" fill="#94a3b8">①収入・経費を</text><text x="110" y="86" text-anchor="middle" font-family="sans-serif" font-size="12" fill="#94a3b8">Excelに記録</text><text x="110" y="110" text-anchor="middle" font-family="sans-serif" font-size="22" fill="#3b82f6">📊</text><rect x="220" y="30" width="160" height="100" fill="#334155" rx="8"/><text x="300" y="68" text-anchor="middle" font-family="sans-serif" font-size="12" fill="#94a3b8">②国税庁サイトで</text><text x="300" y="86" text-anchor="middle" font-family="sans-serif" font-size="12" fill="#94a3b8">申告書作成</text><text x="300" y="110" text-anchor="middle" font-family="sans-serif" font-size="22" fill="#3b82f6">🖥️</text><rect x="410" y="30" width="160" height="100" fill="#334155" rx="8"/><text x="490" y="68" text-anchor="middle" font-family="sans-serif" font-size="12" fill="#94a3b8">③マイナンバーで</text><text x="490" y="86" text-anchor="middle" font-family="sans-serif" font-size="12" fill="#94a3b8">e-Tax送信</text><text x="490" y="110" text-anchor="middle" font-family="sans-serif" font-size="22" fill="#3b82f6">📱</text><rect x="600" y="30" width="160" height="100" fill="#1e3a8a" rx="8"/><text x="680" y="68" text-anchor="middle" font-family="sans-serif" font-size="12" fill="#93c5fd">完了！</text><text x="680" y="86" text-anchor="middle" font-family="sans-serif" font-size="12" fill="#93c5fd">費用 ¥0</text><text x="680" y="110" text-anchor="middle" font-family="sans-serif" font-size="22" fill="#22c55e">✓</text></svg><figcaption style="font-size:.82em;color:#64748b;margin-top:.4em;">e-Taxを使ったアプリ不要の確定申告フロー</figcaption></figure>

**完全無料で確定申告したい方**には、国税庁が提供するe-Taxを使う方法があります。

### 必要なもの
- マイナンバーカード（ICカードリーダーかスマホ）
- 収入・経費の記録（Excelや手書き帳簿でOK）
- 国税庁「確定申告書等作成コーナー」へのアクセス

### 手順

1. **Excelで収支管理** — 毎月の収入と経費を記録しておく（青色申告なら複式簿記が必要）
2. **国税庁サイトで申告書作成** — [確定申告書等作成コーナー](https://www.keisan.nta.go.jp/){:rel="nofollow" target="_blank"}を開き、ガイドに沿って数字を入力
3. **e-Taxで送信** — マイナンバーカードをスマホにかざして電子署名→税務署に送信
4. **還付は通常1〜2週間後**に指定口座へ振込

### アプリ不要の方法のメリット・デメリット

| 項目 | 内容 |
|------|------|
| ✅ メリット | 費用ゼロ、国税庁公式で安心 |
| ✅ メリット | 毎年の操作方法が変わりにくい |
| ❌ デメリット | 帳簿を自分で作る必要がある |
| ❌ デメリット | 銀行・クレカの自動連携がない |
| ❌ デメリット | 青色申告の仕訳入力がやや難しい |

**取引件数が少ない（月10件以下）副業初心者や、とにかくコストをかけたくない方向けの方法です。**

## まとめ

副業での確定申告ツール選びは、自分のライフスタイルと収益規模に合わせることが重要です。

- **副業初心者・年間取引50件以下** → **freee**（年払いで月¥980〜、初心者向けUI）
- **複数口座・金融連携重視** → **マネーフォワード**（年払いで月¥900〜・税抜、金融機関との連携が豊富）
- **本格的な青色申告・節税重視** → **弥生**（初年度無償キャンペーン、2年目¥11,800/年〜・税抜）
- **農業副業・個人事業** → **ソリマチ**（買い切り・最新版は6万円台）
- **費用ゼロ・取引少ない** → **e-Tax手動**（完全無料）
- **iPhoneだけで完結** → **タックスナップ**（詳細は公式サイト参照）

確定申告を一度習慣化すれば、毎年の作業は大幅に短縮できます。まずは**無料プランや1年無料**から試してみることをおすすめします。
